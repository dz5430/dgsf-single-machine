# Result Files

This folder mirrors the Drive `Results/` folder. Download the complete Drive
folder into this directory, preserving `Tables/`, `F1/`, `F2/`, `F3/`, `F4/`,
and `F5/`.

Large `.xlsx` and `.csv` result files are hosted outside git. The nested folder
layout is part of the reproducibility package; see
`../docs/google_drive_manifest.md` for the current Drive paths.

Generated files from the reproducibility workflow can also be written here.
