# Result Files

This directory layout is part of the production-ready `v1.0.0` release.

This folder mirrors the artifact archive's `Results/` folder. Download the
complete folder into this directory, preserving `Tables/`, `F1/`, `F2/`,
`F3/`, `F4/`, and `F5/`.

Large `.xlsx` and `.csv` result files are hosted outside git. The nested folder
layout is part of the reproducibility package; see
`../docs/artifact_manifest.md` for the expected paths.

Generated files from the reproducibility workflow can also be written here.
